СНЕГОПАД (Snowfall) — анимированные обои для Lively Wallpaper
==============================================================

Падающий снег на HTML5 Canvas. Все параметры настраиваются
прямо в приложении Lively Wallpaper, без правки файлов.

УСТАНОВКА
---------
1. Откройте Lively Wallpaper.
2. Нажмите «+ Add Wallpaper» (Добавить обои) вверху окна.
3. Выберите файл index.html из этой папки
   (либо просто перетащите всю папку в окно Lively).
4. Обои появятся в библиотеке — кликните по ним, чтобы установить
   на рабочий стол.

НАСТРОЙКА
---------
1. В библиотеке Lively наведите курсор на карточку обоев и нажмите
   значок карандаша (Customise / Настройка),
   либо правая кнопка мыши -> «Customise».
2. Откроется панель со всеми параметрами:
   - Количество снежинок      (0 — 1000)
   - Скорость падения         (0 — 10)
   - Угол падения, °          (-90 влево ... 0 вниз ... 90 вправо)
   - Покачивание (ветер)      — живое колыхание снежинок
   - Размер снежинок          (1 — 15 px)
   - Разброс размеров         — от одинаковых до «объёмных»
   - Яркость снежинок
   - Цвет снежинок            (палитра)
   - Цвет фона                (палитра)
   - Затемнение фона снизу    — плавный градиент в цвете фона
3. Настройки применяются мгновенно и сохраняются автоматически.
   Кнопка «Restore Default» возвращает исходные значения.

СОВЕТЫ
------
- Обои можно посмотреть без установки: откройте index.html
  в любом браузере.
- Если вы вручную изменили файлы в этой папке, удалите обои
  из библиотеки Lively и добавьте заново — приложение работает
  со своей копией файлов.

ФАЙЛЫ
-----
  index.html            — страница обоев
  snow.js               — логика анимации снега
  LivelyProperties.json — описание настроек для панели Lively
